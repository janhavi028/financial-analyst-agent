# Financial Analyst Agent

An applied LLM project exploring how open-source language models can be
used to perform evidence-grounded analysis of company annual reports.

## Project goals

The project will investigate:

- retrieval and extraction of financial information from annual reports
- LLM tool use for financial analysis
- deterministic calculation of financial metrics
- evidence-grounded answers with source references
- LLM evaluation and failure analysis
- LoRA/PEFT post-training for improved tool use and structured reasoning

The project will compare base-model, few-shot and fine-tuned approaches
using task-level evaluation.
